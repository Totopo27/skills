# Plantilla: Ficha de Aislamiento Visual A5 (Simulación Monocrómica)

Esta plantilla permite al agente renderizar individualmente cada candidato de la Shortlist para evaluar su presencia estética y solvencia tipográfica sin distracciones de contexto.

---

```markdown
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│                                                                              │
│                                                                              │
│                                                                              │
│                              [ NOMBRE CANDIDATO ]                            │
│                                                                              │
│                                                                              │
│                                                                              │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

### Ficha Técnica de Aislamiento:
- **Candidato**: [Nombre en mayúsculas / minúsculas / versalitas]
- **Métrica y Estructura**: [N° de sílabas] | [Patrón: ej. Consonante-Vocal-Consonante]
- **Tipología**: [Evocativo / Neologismo / Etimológico / Slang / Glosario]
- **Diagnóstico Visual**:
  - [x] Solidez tipográfica: ¿Se sostiene negro sobre blanco sin necesidad de logotipo?
  - [x] Fluidez fonética: ¿Se lee y pronuncia sin tropiezos al primer golpe de vista?
  - [x] Contundencia estética: ¿Ocupa el espacio visual con autoridad y equilibrio?
- **Territorio Conceptual**: [Cluster semántico al que pertenece]
- **Veredicto de Aislamiento**: [Aprobado para Shortlist / Requiere ajuste / Descartado]
```
